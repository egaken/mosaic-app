# ▦ モザイク加工くん (Mosaic App)

画像を読み込み、指定した箇所に好みの形状とスタイルでモザイクや目線をかけられる、ミニマル＆モダンなWebアプリケーションです。  
非破壊編集に対応しており、配置したモザイクや目線を後からクリックして移動・リサイズ（拡大縮小）・削除が自由に行えます。

🌐 **公開URL (Google Cloud Run)**:  
👉 **[https://mosaic-app-895652417344.asia-northeast1.run.app](https://mosaic-app-895652417344.asia-northeast1.run.app)**

---

## ✨ 主な機能

1. **画像の読み込み**:
   - ドラッグ＆ドロップ（画面全体どこでも対応）
   - ファイル選択ダイアログ
   - クリップボードからの貼り付け（`Cmd + V` / `Ctrl + V`）
   - ワンクリックで試せるサンプル画像生成（ダミー社員証）

2. **形状ツールの選択**:
   - **四角形**: 矩形範囲をドラッグして隠す
   - **円形／楕円**: 顔やアイコンに最適な楕円加工
   - **フリーハンド（ペン）**: なぞった軌跡を加工（太さ8〜64px可変）

3. **隠し方スタイルの選択**:
   - **モザイク（ピクセル化）**: スライダーでタイルの粗さを直感的に調整
   - **すりガラス風ぼかし**: 上品なガウスブラー効果
   - **単色塗りつぶし**: ニュースのような黒塗り・白塗りの目線バー
   - **絵文字スタンプ**: 😎, 🐱, 🌸, 🙈, 🐶, ⭐, 💖, 🤐 などのスタンプで可愛く目隠し

4. **直感的な編集・微調整機能（非破壊）**:
   - ドラッグ操作中は下地が見える「**半透明＋点線枠**」で表示
   - 配置後にクリックして選択 ➔ 枠を掴んで**位置移動**
   - 8箇所の白いハンドルを引っ張って**自由な拡大・縮小（リサイズ）**
   - `Delete` キーまたはボタンで**単体削除**

5. **高度な加工 & 補助機能**:
   - **🌟 逆モザイク（背景ぼかし）**: 囲んだ主役以外を一眼レフ風にすりガラスぼかし（ポートレートモード）
   - **👁️ ビフォー／アフター比較**: `Tab` キーまたはボタン長押しで瞬時に未加工の元画像を確認
   - **ズーム＆パン**: マウスホイールで拡大縮小、`Space + ドラッグ` で画面を自由に移動
   - **Undo / Redo**: `Cmd + Z` / `Cmd + Shift + Z` で何度でもやり直し可能

6. **保存・エクスポート**:
   - **JPEG形式**: 横幅1200pxに自動リサイズ保存（アスペクト比維持、白背景補完）
   - **PNG形式**: 元画像の等倍オリジナル解像度で最高画質保存
   - ファイル名の先頭に自動でプレフィックス「`m-`」を付与（例: `m-photo.jpg`）

## ⌨️ キーボードショートカット一覧

| キー | 動作 |
| :--- | :--- |
| **<kbd>Tab</kbd> (長押し)** | 元画像とビフォーアフター比較 |
| <kbd>V</kbd> | 選択・移動・変形ツール |
| <kbd>R</kbd> | 四角形ツール |
| <kbd>O</kbd> | 円形・楕円ツール |
| <kbd>P</kbd> | フリーハンドペンツール |
| <kbd>H</kbd> または <kbd>Space</kbd> + ドラッグ | 画面移動（パン操作） |
| マウスホイール | 拡大・縮小（ズーム） |
| <kbd>Cmd</kbd> + <kbd>Z</kbd> | 元に戻す（Undo） |
| <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> | やり直す（Redo） |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | 選択中の加工を削除 |
| <kbd>Esc</kbd> | 選択解除 |
